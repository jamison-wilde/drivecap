# Drivecap v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship drivecap 0.1.0 — a per-user-MSI Windows tray app that watches volume free space and shows an always-on-top, never-focus-stealing stack card (design option 2a) with escalating, debounced, snoozable warnings.

**Architecture:** One crate `drivecap-cli` (lib + `drivecap` bin), plumbing copied from exbar. Pure, unit-tested cores (`config`, `alerts`, `model`, `visibility`, `layout`, `raster`, `controller`, `menu`) hold every decision; thin Win32 adapters (`volumes`, `net_probe`, `paint`, `card_wnd`, `tray`, `popup_wnd`, `contextmenu`, `font`) execute the controller's `Effect`s (ADR-0003 pure-controller pattern, ADR-0004 trait seams).

**Tech Stack:** Rust 2024, `windows` 0.61 (GDI, layered windows, `Shell_NotifyIconW`, `DeviceIoControl`, `ChooseFontW`), serde/serde_json, clap 4, log, thiserror; WiX v7 MSI.

**Spec:** `docs/superpowers/specs/2026-11-15-drivecap-design.md` + visual spec `docs/design/handoff/README.md` (option 2a; spec §5 overrides apply). Executors read both.

### Builder's calls (decided here — spec §8)

| Item | Decision |
|---|---|
| Debounce re-arm | Level L re-arms when free > L + step; re-arming the threshold level clears "last warned". Dire entry re-arms when free > dire + step. |
| Module names | As in Touched files. |
| Config schema | §Task 3 (camelCase JSON). |
| Header glyphs | GDI-drawn: "Zz" text; opacity = circle outline with left half filled; gear = 8-tooth polygon + hole; chevron = 2-segment polyline. |

| Single instance | Named mutex `Local\Drivecap-SingleInstance-v1`; second instance posts registered message `Drivecap.Show` to `FindWindowW("DrivecapCard")` and exits 0. |
| "Disable disk warnings" | Becomes **Quit drivecap** (no pause mode in v1). |
| "Hide this volume" | Sets that volume's config entry `enabled: false` (same as unchecking it in Volumes ▸). |
| Dire + "Next level" snooze | Falls back to a 10-min timed snooze. |
| Timed snooze expiry | A still-warning volume gets an immediate reminder. |
| Tray left-click | Show reason `Tray`: forced expanded mode for that showing, fade in 200 ms to 100 %, hold 6 s, normal hover/linger; click again while visible hides. Mode reverts when hidden. |
| Right-click ▸ Snooze | Over a row → that volume; elsewhere/tray → all at-risk volumes. |
| Popup dismissal | Popups stay `WS_EX_NOACTIVATE`; while open the anim timer polls `GetAsyncKeyState` for Esc and for a mouse-button press outside popup+card. |
| Runtime alert state | Not persisted; restart re-warns current level. |
| Malformed config | Run on defaults, log a warning, never overwrite the file until it parses again. |
| Missing config | Write defaults on first run. |
| Volume rescan | At start, on `WM_DEVICECHANGE` (`DBT_DEVICEARRIVAL`/`DBT_DEVICEREMOVECOMPLETE`), on config reload, every 300 s. |
| Config reload | Tick checks `config.json` mtime every 2 s; own saves update the remembered mtime. |
| Free-space value | `lpFreeBytesAvailableToCaller` of `GetDiskFreeSpaceExW`. |
| Value text | `< 1 GB` → `"850 MB"`; `< 100 GB` → one decimal `"14.8 GB"`; `< 1000 GB` → `"245 GB"`; else `"1.2 TB"`. |

## Review Focus

1. **Free space jittering across a level during a build** (14.99 ↔ 15.01 GB for minutes) → exactly one warning. Test: Task 4 `jitter_across_level_warns_once`.
2. **Hand-edited config.json that is malformed or has an impossible rule** (dire ≥ threshold, step 0, negative) → app runs, bad rule falls back to defaults, file not overwritten. Tests: Task 3 `malformed_json_is_not_writable`, `invalid_rule_falls_back_to_defaults`.
3. **USB drive plugged/unplugged or letter removed mid-run** → row appears/disappears, rule follows the GUID, no stale row, no panic on a sample for a vanished volume. Test: Task 10 `rescan_removes_vanished_and_ignores_late_sample`.
4. **Saved position on a monitor that no longer exists, or off-screen after a resolution change** → card lands fully inside a current work area. Tests: Task 7 `missing_monitor_uses_default`, `offscreen_position_clamped`.
5. **Odd sizes**: 0 bytes free, multi-TB healthy drives, rule where dire ≥ lowest step, threshold not a multiple of step → no panic, sensible levels/bar. Tests: Task 4 `levels_stop_above_dire`, Task 5 `format_free_ranges`, `bar_fill_clamps`.

### Task 4: Alert engine (zones, levels, debounce, snooze, schedule)

**Files:** Create `src/alerts.rs`.

**Interfaces — Consumes:** `config::{Rule, Timings, SnoozeChoice, GIB}`.
**Produces:**
```rust
pub enum Zone { Healthy, Warning, Dire, Unreachable }             // Ord: severity_rank() Dire=0, Warning=1, Healthy=2, Unreachable=3
pub enum Sample { Free(u64), Unreachable }
pub enum Snooze { Off, Until { at_ms: u64, choice: SnoozeChoice }, NextLevel }
pub enum AlertEvent { Crossing, EnteredDire, Reminder, BecameUnreachable }
pub fn levels(rule: &Rule) -> Vec<u64>;          // threshold, threshold-step, … while > dire (descending)
pub fn zone_for(free: u64, rule: &Rule) -> Zone; // free > threshold Healthy; > dire Warning; else Dire
pub fn reminder_interval_ms(free: u64, rule: &Rule, t: &Timings) -> u64;  // linear max@threshold → min@dire, clamped
#[derive(Default)] pub struct VolumeAlert { pub free: Option<u64>, pub zone: Zone(default Healthy), pub snooze: Snooze, /* private: last_warned: Option<u64>, dire_warned: bool, next_reminder_at: Option<u64>, unreachable_since: Option<u64> */ }
impl VolumeAlert {
  pub fn observe(&mut self, s: Sample, rule: &Rule, now: u64, t: &Timings) -> Option<AlertEvent>;
  pub fn tick(&mut self, rule: &Rule, now: u64, t: &Timings) -> Option<AlertEvent>;   // timed snooze expiry, due reminders
  pub fn snooze(&mut self, choice: SnoozeChoice, now: u64);
  pub fn wake(&mut self, now: u64);
  pub fn is_snoozed(&self, now: u64) -> bool;
  pub fn is_at_risk(&self) -> bool;                         // Warning | Dire
  pub fn reminder_shown(&mut self, rule: &Rule, now: u64, t: &Timings); // surface shown for any reason → reset next_reminder_at = now+interval
  pub fn poll_interval_ms(&self, rule: &Rule, base_secs: u64, t: &Timings) -> u64; // Healthy/Unreachable base; Warning min(base, reminder); Dire min(base, reminder_min)
  pub fn show_in_minimized(&self, now: u64, t: &Timings) -> bool; // at risk && !snoozed, or Unreachable && now - since < drop
}
```
